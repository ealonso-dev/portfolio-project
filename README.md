# portfolio-project 
## Accessibility Fixes
- I fixed the low contrast in my footer across `index.html`, `about.html`, and `projects.html` by changing it to dark text on a white background so it passes WAVE and WebAIM contrast checks.
- I removed messy code text that I had accidentally pasted into the footer so the page displays cleanly.
- I added a contact form to `about.html` with `<label>` tags, `<fieldset>` and `<legend>` grouping, and error messages so people can use it with screen readers.

## Visual Design & Gestalt Principles
- **Common Region:** I used `<section class="card">` boxes across my pages to keep each topic in its own separate section.
- **Similarity:** I kept the same header, navigation bar, colors, and tag styles across `index.html`, `about.html`, and `projects.html` so the pages look like they belong together.
- **Proximity:** On `projects.html`, I kept each project's title, description, bullet points, and skill tags close together inside its own card so you can tell what goes with each project.
